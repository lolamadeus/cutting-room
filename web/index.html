Cutting Room

Review footage, mark the best bits, and plan the edit. One project per video.

Start a new project

  1. In the cutting-room folder, run python engine\new_project.py "My Project" "C:\path\to\clips"
  2. Optionally edit projects\<id>\project.json: target length, groups, highlight tags
  3. Run python engine\prepare.py <id> to make proxies, filmstrips and waveforms
  4. Refresh this page and open it
